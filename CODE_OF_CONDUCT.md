# Code of Conduct

## Our Standard

This project is committed to a respectful, constructive, and inclusive community.

We expect all participants to:

- Be respectful in language, tone, and feedback
- Assume good intent while still being clear and direct
- Focus criticism on ideas, code, and behavior, not people
- Welcome contributors with different backgrounds and experience levels
- Accept feedback gracefully and course-correct when needed

## Unacceptable Behavior

The following behavior is not acceptable:

- Harassment, insults, threats, or discriminatory language
- Personal attacks, trolling, or bad-faith engagement
- Publishing private information without permission
- Sexualized language or imagery in project spaces
- Repeatedly derailing discussions or refusing reasonable moderation requests

## Scope

This code of conduct applies to project spaces, including issues, pull requests, code review, and other public or private interactions tied to the repository.

## Reporting

If you experience or witness unacceptable behavior, contact the maintainer privately through GitHub at [@nikkogibler](https://github.com/nikkogibler).

## Enforcement

The maintainer may remove comments, close discussions, reject contributions, or block participants whose behavior violates this code of conduct.

Enforcement decisions aim to protect the project and the people participating in it.
